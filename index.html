This college project ran from early February to March 26th. We were tasked with installing and configuring an ERPNext system on a server according to our client’s requirements, specifically the education module, and producing comprehensive documentation.

View Full Documentation

Project Workflow

Our team followed a weekly meeting schedule to discuss progress, review completed tasks, and plan upcoming work. Attendance was crucial to ensure effective coordination and timely completion of project milestones.

Technologies Used

For this project, we leveraged the following tools and platforms:

  • Linux server (rented from IONOS, Spain)
  • Ubuntu
  • ERPNext (Education module)
  • Docker
  • GitBook for documentation

Challenges & Solutions

  • The initial ERPNext installation on the server was challenging due to the manual setup process. We successfully overcame this by using Docker on our second attempt, which simplified deployment and configuration.
  • Team members were initially unfamiliar with ERPNext and its Doctype system. Through collaborative learning and hands-on practice, we quickly adapted and became proficient in configuring modules effectively.
